One-line office joke for make.fun's "One-Line Office Joke: 24-Hour Sprint" bounty, $2 in USDC. The program writes a single one-line joke about office life to `entry.txt` — a joke about the office printer that only ever jams on urgent documents.

> The office printer only jams on documents marked urgent, which is how I know it can read.

One sentence, one line, 89 characters — inside the 200-character gate.

## Run it

```sh
python3 main.py
```

The joke is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and printed to stdout.
